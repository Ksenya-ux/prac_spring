Python-MOOD Documentation
==========================

Многопользовательский текстовый мир (MUD) на Python с асинхронной архитектурой.

Техническое задание: Реализация системы бродячих монстров
----------------------------------------------------------

Цель
~~~~

Реализация автоматического перемещения монстров на сервере MUD с поддержкой энкаунтеров при столкновении с игроками.

Функциональные требования
~~~~~~~~~~~~~~~~~~~~~~~~~~

1. **Периодичность перемещения**
   Каждые 30 секунд после запуска сервера выполняется одно перемещение случайно выбранного монстра.

2. **Механика перемещения**
   Случайный монстр перемещается на одну клетку в случайном направлении (вправо, влево, вверх, вниз). Игровое поле является закольцованным.

3. **Обработка коллизий**
   Если  клетка занята другим монстром, текущая попытка перемещения отменяется. Система осуществляет повторный выбор монстра и направления до достижения успешного перемещения.

4. **Оповещение игроков**
   При каждом перемещении всем подключенным игрокам направляется системное сообщение формата:
   ``<имя_монстра> moved one cell <направление>``

5. **Система энкаунтеров**
   При попадании монстра на клетку, занятую одним или несколькими игроками, инициируется процедура энкаунтера, эквивалентная ситуации, когда игрок самостоятельно заходит на клетку с монстром. Монстр отрисовывается с использованием cowsay и произносит приветственную фразу для каждого игрока на данной клетке.
